Production Deployment Guide

Step-by-step instructions to deploy the Charlton Exclusive Club application to a live production server.

1
Server Requirements & Prerequisites

Ensure your production server (VPS running Ubuntu 22.04/24.04 or similar Linux distribution) has the following software installed:

  • PHP 8.3 with extensions: Ctype, cURL, DOM, Fileinfo, Filter, Hash, Mbstring, OpenSSL, PCRE, PDO, Session, Tokenizer, XML, GD or Imagick, Zip.
  • Composer 2.x
  • Node.js 18+ & NPM (for Vite asset compilation)
  • MySQL 8.0+ or MariaDB 10.6+
  • Nginx or Apache web server
2
Clone Repository & Set Document Root

Clone your repository into your web root directory (e.g., /var/www/charltonexclusive):

git clone https://github.com/your-username/charltonexclusive.git /var/www/charltonexclusive
cd /var/www/charltonexclusive

Configure your web server (Nginx/Apache) document root to point to the /public directory of the project: /var/www/charltonexclusive/public.

3
Configure Environment Variables (.env)

Copy the environment template and configure production settings:

cp .env.example .env
php artisan key:generate

Open .env and update critical production variables:

APP_NAME="Charlton Exclusive Club"
APP_ENV=production
APP_DEBUG=false
APP_URL=https://yourdomain.com

DB_CONNECTION=mysql
DB_HOST=127.0.0.1
DB_PORT=3306
DB_DATABASE=charlton_production
DB_USERNAME=db_user
DB_PASSWORD=secure_password

STRIPE_KEY=pk_live_...
STRIPE_SECRET=sk_live_...
STRIPE_WEBHOOK_SECRET=whsec_...
4
Install Dependencies & Build Assets

Install optimized PHP dependencies without dev packages and build production frontend assets:

composer install --no-dev --optimize-autoloader
npm install
npm run build
5
Run Database Migrations

Run migrations against your production database:

php artisan migrate --force
6
Set File Permissions & Ownership

Ensure the web server user (e.g., www-data) has write access to storage and cache directories:

sudo chown -R www-data:www-data /var/www/charltonexclusive
sudo chmod -R 775 /var/www/charltonexclusive/storage /var/www/charltonexclusive/bootstrap/cache
7
Optimize Laravel (Caching)

Cache configuration, routes, and views for maximum performance in production:

php artisan config:cache
php artisan route:cache
php artisan view:cache
8
Configure Queue Workers & Scheduler (Cron)

1. Setup Cron for Laravel Scheduler: Add this entry to your server crontab (crontab -e):

* * * * * cd /var/www/charltonexclusive && php artisan schedule:run >> /dev/null 2>&1

2. Setup Supervisor for Queues: Create a supervisor configuration file at /etc/supervisor/conf.d/charlton-worker.conf:

[program:charlton-worker]
process_name=%(program_name)s_%(process_num)02d
command=php /var/www/charltonexclusive/artisan queue:work --sleep=3 --tries=3 --max-time=3600
autostart=true
autorestart=true
user=www-data
numprocs=2
redirect_stderr=true
stdout_logfile=/var/www/charltonexclusive/storage/logs/worker.log

Then start/update Supervisor:

sudo supervisorctl reread
sudo supervisorctl update
sudo supervisorctl start charlton-worker:*
Deployment Complete! Your application is now fully configured and optimized for live production traffic. Remember to configure your SSL certificate (e.g. via Certbot for Let's Encrypt) and point your domain DNS records to your server IP address.
